# 11. Desktop UI

A `window` block describes an interface. It redraws every frame, so labels always match
your state.

```plaintext
counter = 0

make function called increment() {
    increase counter by 1
}

window "Counter" (width: 420, height: 260) {
    column (padding: 24, spacing: 16, align: center) {
        text "You clicked {counter} times" (size: 26)
        button "More" (on_click: increment)
    }
}
```

Widgets: `column`, `row`, `text`, `button`, `spacer`.  
Useful properties: `padding`, `spacing`, `align`, `size`, `width`, `height`, `color`, `bg`,
`font`, `sprite`, `on_click`.
