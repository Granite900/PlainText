# 11. Desktop UI

**Goal:** Describe a window with columns, labels, and buttons that stay in sync with your data.

## The `window` block

A UI redraws every frame. Labels with `{counter}` always show the current value — you do
not manually “refresh” the text.

```plaintext
counter = 0

make function called increment() {
    increase counter by 1
}

window "Counter" (width: 420, height: 260) {
    column (padding: 24, spacing: 16, align: center) {
        text "You clicked {counter} times" (size: 26)
        button "More" (on_click: increment)
    }
}
```

## Widgets and properties

| Widget | Role |
|--------|------|
| `column` / `row` | Layout |
| `text` | Label (supports interpolation) |
| `button` | Clickable; use `on_click: some_function` |
| `spacer` | Empty space |

Useful properties: `padding`, `spacing`, `align`, `size`, `width`, `height`, `color`,
`bg` (window background), `font`, `sprite` (button face).

## Practice

Run the polished counter:

```bash
plaintext run examples/counter.pt
```

It shows colors, sized buttons, and a sprite. Read the comments at the top for optional
custom fonts on Windows / macOS.
